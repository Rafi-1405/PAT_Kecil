Keyframe per aktor

Mode lihat saja. Spasi: play/pause. Klik baris naskah atau balok durasi untuk meloncat ke waktunya. Tekan ? untuk daftar pintasan.

Masukkan waktu playback di atas dan tekan Enter untuk loncat presisi sebelum menempatkan aktor. Klik keyframe untuk memilih satu; Ctrl/Cmd+klik untuk tambah atau lepas pilihan; Shift+klik untuk memilih rentang. Pilih Semua dan Backspace mengatur pilihan massal. Format waktu SS, MM:SS.s, atau HH:MM:SS.s. Seret aktor ke panggung untuk membuat keyframe. Ctrl+Z / Ctrl+Y untuk undo/redo; tekan ? untuk semua pintasan.

Pintasan Keyboard

Semua mode
  • Spasi play / pause
  • ← → mundur / maju 1 dtk (Shift = 5 dtk)
  • ↑ ↓ baris naskah sebelumnya / berikutnya
  • [ ] adegan sebelumnya / berikutnya
  • Home End ke awal / akhir
  • < > kecepatan lebih lambat / cepat
  • N tampil / sembunyikan naskah   B Babak View
  • ? bantuan ini   Esc tutup
Mode Editor
  • Ctrl+Z undo   Ctrl+Y atau Ctrl+Shift+Z redo
  • Ctrl+S simpan & publikasi ke GitHub
  • Backspace hapus keyframe yang dipilih pada timeline
  • Waktu playback: masukkan SS, MM:SS.s, atau HH:MM:SS.s, lalu tekan Enter
  • E Edit mode naskah on / off
  • Saat mengetik di naskah: Enter simpan (di akhir teks: sisip dialog baru), Ctrl+Enter sisip dialog di bawah, Shift+Enter simpan saja, Esc batal
