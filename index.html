Seret aktor ke titik mana saja di panggung (garis grid hanya penanda) untuk menyimpan koordinatnya pada waktu sekarang. Seret aktor di panggung ke tray untuk keluar panggung. Klik dua kali aktor di panggung untuk menghapus keyframe-nya. Spasi: play/pause. Di panel naskah (Edit mode aktif): klik dua kali waktu = memindahkan baris itu saja; klik dua kali durasi = memanjangkan/memendekkan baris itu dan menggeser semua yang setelahnya (adegan, babak, blocking). Format SS, MM:SS.s, atau HH:MM:SS.s; Enter menyimpan, Esc membatalkan. Ctrl+Z / Ctrl+Y untuk undo/redo; tekan ? untuk semua pintasan.

Pintasan Keyboard

Semua mode
  • Spasi play / pause
  • ← → mundur / maju 1 dtk (Shift = 5 dtk)
  • ↑ ↓ baris naskah sebelumnya / berikutnya
  • [ ] adegan sebelumnya / berikutnya
  • Home End ke awal / akhir
  • < > kecepatan lebih lambat / cepat
  • N tampil / sembunyikan naskah   B Babak View
  • ? bantuan ini   Esc tutup
Mode Editor
  • Ctrl+Z undo   Ctrl+Y atau Ctrl+Shift+Z redo
  • Ctrl+S unduh HTML terbaru
  • E Edit mode naskah on / off
  • Saat mengetik di naskah: Enter simpan (di akhir teks: sisip dialog baru), Ctrl+Enter sisip dialog di bawah, Shift+Enter simpan saja, Esc batal
